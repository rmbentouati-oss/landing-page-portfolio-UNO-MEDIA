# UNO MEDIA 🌐

A modern and responsive portfolio website for **UNO MEDIA**, a digital marketing and content creation company.

The website presents the company's services, training programs, and content marketing solutions through a clean Arabic-focused design with a right-to-left (RTL) layout.

## ✨ Features

- **Responsive Design:** Adapts to different screen sizes and devices.
- **Arabic RTL Layout:** Provides a user-friendly experience for Arabic-speaking visitors.
- **Company Introduction:** Presents UNO MEDIA and its mission.
- **Services Section:** Showcases the company's digital marketing and content creation services.
- **Training Programs:** Highlights available courses and training opportunities.
- **Course Registration:** Includes a registration button connected to Google Forms.
- **Social Media Integration:** Provides quick access to Instagram and WhatsApp through floating contact buttons.
- **Contact Options:** Makes it easier for visitors to connect with the company.
- **Clean User Interface:** Offers a modern layout with clear sections and navigation.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, and responsive design.
- **JavaScript** — Interactive website functionality.
